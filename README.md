# Plataforma-de-Monitoreo-de-Conectividad-M-vil-Rural
Este repositorio contiene el prototipo funcional de un dashboard para el monitoreo de la señal móvil en zonas rurales, especialmente en escenarios afectados por cortes eléctricos. El proyecto se desarrolló siguiendo la metodología de Ingeniería de Sistemas, estructurando el sistema como un entorno socio-técnico donde interactúan datos, usuarios y componentes tecnológicos.

# Funcionalidad principal

El dashboard permite:

Visualizar datos de señal móvil (RSRP) y eventos asociados a cortes eléctricos.

Registrar incidencias mediante un formulario simulado.

Analizar la información de manera integrada para apoyar la toma de decisiones.

Mostrar un flujo funcional del sistema, demostrando la viabilidad técnica del prototipo.

# Arquitectura del sistema

El sistema está organizado en módulos independientes pero interconectados:

Módulo de captura de datos: permite ingresar y simular información de señal y eventos.

Módulo de procesamiento: analiza los datos para generar métricas y reportes.

Módulo de visualización: despliega la información en gráficos y tablas para facilitar su interpretación.

Esta modularidad permite reemplazar los componentes simulados por dispositivos o sensores reales en futuras implementaciones, sin modificar la lógica central del sistema.

# Tecnologías utilizadas

React (o tu framework preferido para frontend)

Librerías de visualización de datos (Chart.js)

Formularios para simulación de entradas de datos

Context API / State Management para flujo de información

# Propósito

Este prototipo sirve como demostración de concepto, mostrando cómo la Ingeniería de Sistemas permite organizar, procesar y visualizar información para apoyar decisiones estratégicas en entornos con conectividad limitada.
